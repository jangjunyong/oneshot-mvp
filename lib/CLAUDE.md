# lib/ — 계산만 한다

여기 있는 것은 **순수 함수**다. fetch·파일쓰기·전역상태·랜덤·시계 금지.
같은 입력에 항상 같은 결과가 나와야 한다 (eval 14).

## 닮음의 다섯 축

`PRD.md` "무엇을 닮았다고 하는가" 절과 **숫자가 같아야 한다.** 한쪽만 고치지 말 것.

| 축 | 계산 | 가중치 |
|---|---|---|
| 접근성 | `abs(a1-a2) / 4` | 0.30 |
| 인구 | `min(1, abs(log p1 - log p2) / log 10)` | 0.30 |
| 지역 | `min(1, haversine_km / 300)` | 0.20 |
| 시기 | 월 원형거리 `min(d, 12-d) / 6` | 0.10 |
| 테마 | 코드 일치 0 / 불일치 1 | 0.10 |

가중합이 `DISTANCE_THRESHOLD` 를 넘으면 **결과에서 뺀다.** 3개를 채우려고 억지로 가장 가까운 걸 넣지 않는다 (eval 08).

## 하지 말 것

- **`preSearchSurge` 를 특징 벡터에 넣기** — 59%가 아티팩트다. 1.00 이 264건, 10.00 이 98건
- **축제 기간을 축으로 되살리기** — 상관 -0.17 로 노이즈라 뺐다
- **방문객 수를 만들어내기** — 어떤 형태로든. `actualVisitSurge` 는 실측값이니 그대로 옮기기만 한다
- 값이 없을 때 그럴듯한 기본값으로 채우기 — 없으면 없다고 반환한다
