# app/result/ — 경보를 보여주는 화면

`app/CLAUDE.md` 를 그대로 따르고, 여기에 더한다.

## 등급 문구

`lib/types.ts` 의 `GRADE_CUT` 을 쓴다. 숫자를 여기 다시 적지 말 것.

| 닮은 축제들의 중앙 배수 | 화면 |
|---|---|
| 2.00 이상 | **경보: 심각** |
| 1.50 ~ 2.00 | **경보: 주의** |
| 1.50 미만 | **위험 근거 못 찾음** |
| 닮은 축제 0곳 | **비교할 만한 과거 축제가 없습니다** + 찾아본 범위 |

아래 두 칸은 경보가 아니다. **경고색을 쓰지 않는다.**

## 반드시 같이 나가는 것

과거 축제 한 건을 화면에 올릴 때는 **배수 · 개최 연도 · 출처** 셋이 붙는다. 하나라도 없으면 올리지 않는다.

"왜 닮았나"는 다섯 축 중 **무엇이 닮았는지 항목으로** 보여준다. 유사도 점수만 던지지 않는다.
