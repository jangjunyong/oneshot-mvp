## 절대 어기지 않는 것 (제품 불문율)

1. **방문객 수를 예측하지 않는다.** 화면에 나가는 숫자는 과거가 실제로 겪은 *평소 대비 배수*뿐이다.
2. **"안전하다"고 말하지 않는다.** 근거를 못 찾은 것과 안전한 것은 다르다.
3. **왜 닮았는지를 항상 같이 낸다.** 유사도 점수만 던지면 실무자는 못 믿는다.
4. **출처 없는 숫자·그림을 화면에 올리지 않는다.** 못 구한 값은 비우고 "못 구했다"고 적는다.
5. **판정·시뮬에 LLM 0회.** 모델은 기획서에서 항목을 옮겨 적는 1회만.

## 반드시 알아야 할 사실 (여기서 시간 날린다)

### TourAPI
- `contentid` **= 619건 데이터의 `id`** 다. 그래서 조인이 된다(2026-10 축제 140건 중 26건 일치).
- `searchFestival2` 에 **`areaCode` 를 주면 0건**이 온다. 좌표(mapx=경도, mapy=위도)가 다 있으니 반경으로 거른다.
- **미래 축제는 등록이 거의 없다**(2027-05 조회 0건). 그래서 같은 시기 경쟁은 *가장 최근에 지난 그 달*을 본다.
- `homepage` 는 `<a href=…>` 앵커로 올 때가 있다 → `homepageUrl()` 로 주소만 꺼낸다.
- 키는 `.env.local`·Vercel 에만 있다. **e2e 는 "키 없음"이 전제**라 빈 문자열로 덮는다(`delete` 로는 안 된다 — next start 가 도로 채운다).

### 지도·도면
- 브이월드 백지도는 **z6~18**(z19 는 XML 오류). OSM·Esri 위성은 z5~19. `tilemap.ZOOM_LIMITS` 에 실측으로 박아 뒀다.
- **크기의 진실은 미터다.** `lib/venue.ts` 의 `KIND_SIZE_M`. 픽셀은 축척(`mPerPx`)에서 나온다.
  예전에 픽셀 고정이라 줌 16 에서 **117m 부스**가 생겼다 — 재발 방지 테스트가 있다.
- 부지 경계는 `kind:"site"` 폴리곤 하나. 면적은 신발끈×축척², 경계 밖은 네 모서리 판정.

### 작업 규약
- 새 의존성은 **추가 전 질문**. `any` 금지. 주석은 "왜"만. 문서·UI 문구는 한국어. 커밋은 기능 단위.
- 사이클: 순수 함수 TDD → 화면 → `npm test`·`typecheck`·`lint`·`build`·`test:e2e` → 크롬으로 직접 확인 → 커밋 → main push(=Vercel 자동배포).
- **화면 확인 요령**: `npm run build` 후 `DATABASE_URL= npx next start --port 3200`.
  빌드 후에는 **서버를 반드시 재시작**해야 새 화면이 나온다. 진단 이력은 e2e 와 같은 방식으로 서버 액션에 폼을 POST 해서 심는다.
- 크롬 자동화: 팔레트·버튼은 **하이드레이션 후 다시 `find` 해서 얻은 ref** 로 눌러야 먹는다. 캔버스 드래그는 Konva 가 합성 이벤트를 안 받아 안 된다.
