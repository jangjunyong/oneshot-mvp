## 절대 어기지 않는 것 (제품 불문율)

1. **방문객 수를 예측하지 않는다.** 화면 숫자는 과거가 실제로 겪은 *평소 대비 배수*뿐이다.
2. **"안전하다"고 말하지 않는다.** 근거를 못 찾은 것과 안전한 것은 다르다.
3. **왜 닮았는지를 항상 같이 낸다.** 유사도 점수만 던지면 실무자는 못 믿는다.
4. **출처 없는 숫자·그림을 화면에 올리지 않는다.** 못 구한 값은 비우고 "못 구했다"고 적는다.
5. **판정·시뮬에 LLM 0회.** 모델은 기획서에서 항목을 옮겨 적는 1회만.

`evals/cases.md` 09행이 4번의 판정 기준이다. **2026-08-31 에 판정 문장을 고쳤다** —

## 반드시 알아야 할 사실 (여기서 시간 날린다)

### 이 코드가 거짓말하기 쉬운 자리 (2026-08-31 적대적 검증에서 나온 것)

전부 같은 병이었다 — **재지 못한 것이 "안심" 쪽으로 기운다.** 새 기능을 붙일 때
"이 값이 결측이면 화면이 뭐라고 말하나"를 먼저 물을 것.

- **감당 범위 하한은 언제나 1.00 이다.** `localBaseline` 이 `matched` 안에서 기준을
  고르므로 `twinLo ≤ baseSurge` 가 늘 참이다(619건 중 기준이 있는 136건 전수 확인).
  측정값이 아니라 항등식이라 화면이 그렇게 말한다. **구간처럼 내지 말 것.**
- **`scanSeason` 은 부분 결측에서 거짓말한 적이 있다.** 12달 중 1달만 재도 `spread=0`
  이라 `flat` 이 참이 됐고 화면이 "시기는 갈리지 않습니다"라고 적었다. 지금은
  `measured` 를 싣고 `flat` 은 12달을 다 재야 참이 된다. `robust`·`monthMatchRate` 도
  같이 게이트했다. **셋 다 결측에 무방비였다 — 하나만 고치면 나머지가 거짓말한다.**
- **시연 사례는 619건과 겹치면 안 된다.** 옛 사례는 축제 등록값 그대로여서
  `findSimilar` 가 자기 자신을 거리 0.00 으로 집었다. `lib/demo.test.ts` 가 지금은
  "자기 자신을 안 집는다"를 못 박는다.
- **저장소의 시연 id 가로채기는 읽기 경로에만 있었다.** 쓰기 경로로 `"demo"` 가
  흘러 `Number("demo")=NaN` 이 BIGINT 에 들어가 배포본에서 100% 실패했다.
  `saveVenue` 에 숫자 가드가 있다. **읽기를 가로챘으면 쓰기도 봐야 한다.**
- **진단서 헤드라인과 목록이 다른 기준으로 정렬된다.** `competitorsNear` 는 거리순,
  `competitionHeadline` 은 배수 최대. 잘라 실으면 지목한 축제가 종이에서 빠진다.

### 지도·도면
- 브이월드 백지도는 **z6~18**(z19 는 XML 오류). `tilemap.ZOOM_LIMITS` 에 실측으로 박아 뒀다.
- **크기의 진실은 미터다**(`KIND_SIZE_M`). 픽셀은 축척에서 나온다. 예전에 픽셀 고정이라 줌 16 에서 117m 부스가 생겼다 — 재발 방지 테스트 있음.
- 뷰 배율: `mPerPx = metersPerPixel(lat, zoom) / view`. 이 한 줄이 정의의 전부다. Konva Stage 는 **스케일하지 않는다**.
- `scaleItems`/`shiftItems` 는 `points` 있는 것(통로·**부지**)을 전부 다룬다.

### 작업 규약
- 새 의존성은 **추가 전 질문**. `any` 금지. 주석은 "왜"만. 문서·UI 문구는 한국어. 커밋은 기능 단위.
- 사이클: 순수 함수 TDD → 화면 → `npm test`·`typecheck`·`lint`·`build`·`test:e2e` → 크롬 확인 → 커밋 → main push(=Vercel 자동배포).
- **화면 확인**: `npm run build` 후 `DATABASE_URL= npx next start --port 3200`. 빌드 후 **서버 재시작 필수**.
  포트가 안 죽으면 PowerShell 로: `Get-NetTCPConnection -LocalPort 3200 -State Listen | %{ Stop-Process -Id $_.OwningProcess -Force }`
  이력은 e2e 의 `폼을낸다` 방식으로 서버 액션에 폼을 POST 해서 심는다.
- **크롬 자동화** — 버튼은 ref 클릭이 화면 배율 때문에 빗나간다. **JS `.click()` 이 확실하다.**
  스크린샷이 자주 타임아웃 난다(재시도하면 된다). 검증은 스크린샷 좌표가 아니라 **DOM 텍스트를 JS 로 읽어서** 한다.
  캡처는 `document.documentElement.style.zoom='0.62'` 로 줄이고 `scrollTo` 로 절대 위치를 잡으면 잘 나온다.
- **진단서 인쇄 높이 재는 법** — 자동 검사가 없으니 손으로 잰다. 진단서를 열고
  CSS 파일의 `@media print` 규칙을 그대로 꺼내 화면에 적용한 뒤 높이를 mm 로 읽는다.
  ```js
  let pr=''; for(const sh of document.styleSheets){let rs;try{rs=[...sh.cssRules]}catch{continue}
   for(const r of rs) if(r.media&&[...r.media].join(',').includes('print'))
     pr+=[...r.cssRules].map(x=>x.cssText.replace(/;/g,' !important;')).join('\n');}
  const st=document.createElement('style');
  st.textContent='body{margin:0}\n.no-print{display:none!important}\n.report{width:186mm!important}\n'+pr;
  document.head.appendChild(st);
  // 가용 273mm 와 견준다
  document.querySelector('.report').getBoundingClientRect().height/(96/25.4)
  ```
  최악을 보려면 경쟁 목록 `li` 를 상한까지 복제하고 축제명을 한 줄 더 흐르게 늘린다.
