# VWorld 지도 키 — 도메인 제한 (검증 S1 #10, 2026-09-14 사용자 결정 A)

## 왜 코드로 숨기지 않나

브이월드 WMTS 타일은 브라우저가 키를 붙여 직접 부르는 방식이다. 지도(`/venue` 위성 배경, `/check` 3D 지도)가 돌려면 키가 페이지에 실린다 — 구조상 정상이다.
막는 곳은 코드가 아니라 **브이월드 관리 화면의 "사용 URL(서비스 도메인)" 등록**이다. 서버 프록시(B안)는 VWorld 가 서버 요청을 받아 주는지 먼저 시험해야 하고, 지도 트래픽이 전부 Vercel 을 거쳐 보류했다.

## 지금 상태 (2026-09-14 실측)

배포본 `/venue` HTML 에서 키를 꺼내 군포 타일 한 장(z16)을 세 가지로 불렀다.

| 요청 | 결과 |
|---|---|
| Referer = oneshot-mvp.vercel.app | 200 PNG 타일 |
| Referer = example.com (남의 사이트) | 200 PNG 타일 |
| Referer 없음 | 200 PNG 타일 |

**제한이 걸려 있지 않다.** 키를 본 누구든 자기 사이트에서 이 키로 타일을 쓸 수 있다.

## 사용자만 할 수 있는 것 (5분)

1. vworld.kr 로그인 → 오픈API → **인증키 관리**(마이페이지). 화면 이름은 브이월드 개편에 따라 다를 수 있다.
2. 이 서비스에 쓰는 키(앞 8자 `3522415E`)를 열어 **서비스 URL / 사용 도메인**을 `https://oneshot-mvp.vercel.app` 로만 둔다.
3. 로컬 개발(`localhost:3000`)에서도 위성 배경이 필요하면 개발용 키를 따로 발급해 `.env.local` 의 `VWORLD_KEY` 에 넣는다. 한 키에 로컬을 같이 등록하면 제한이 느슨해진다.

## 걸었는지 확인하는 법

위 표의 세 요청을 다시 부른다. **남의 사이트·Referer 없음이 타일이 아닌 오류로 바뀌면** 제한이 걸린 것이다. 우리 사이트 요청은 여전히 200 PNG 여야 한다.
브이월드가 Referer 대신 다른 방식으로 도메인을 검사해 셋 다 200 으로 남으면, 그때는 B안(서버 프록시)을 시험한다.
