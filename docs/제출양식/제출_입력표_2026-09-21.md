## 3. 절차에서 걸린 함정 (최종 제출 때 또 만난다)

| 함정 | 증상 | 넘는 법 |
|---|---|---|
| 페이지의 `alert()` | **탭 전체가 얼어** 스크린샷·스크립트가 전부 시간 초과 | 작업 전에 `window.alert` 를 가로채 배열에 모은다. 안 얼고 문구도 읽힌다 |
| 로그인이 sessionStorage | 탭을 닫으면 **로그아웃** | 얼었다고 탭을 닫지 않는다 |
| 이메일 인증번호 단발성 | 같은 번호 재시도 → `인증번호가 일치하지 않습니다` | 한 번에 성공시킨다. 성공 신호는 알림이 아니라 **[인증번호 확인] 버튼이 잠기는 것**(disabled) |
| 인증 뒤에도 행 클릭 시 모달 재등장 | 진입 불가처럼 보인다 | 행 클릭 대신 **상세 해시 주소로 직접 이동** |
| 파일 input 이 선택 직후 비워짐 | `files.length === 0` | 화면의 **파일명 문자열**로 확인 |
| 유형이 신청 때 값으로 남아 있음 | "앱"이면 스토어 URL 이 **필수 누락** = 심사 제외 경로 | 2단계에서 앱 해제 → 웹 체크 → 서비스 URL 칸이 나타나는지 확인 |
