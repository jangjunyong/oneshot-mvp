# 와이어프레임 — 축제 위험 경보

3차 멘토링 02 단계 규격. 색·폰트·아이콘·이미지 없이 **화면 개수와 배치와 이동**만 정한다.
화면마다 정상 / 로딩 / 빈 상태 / 에러 네 장씩. 근거는 `docs/screens.md`(플로우 3·화면 4).

제품: 축제 기획안을 넣으면 닮은 과거 축제 619건에서 실측 근거를 찾아 경보 등급을 낸다.
사용자: 예산 집행 전 기획안을 검증해야 하는 지자체 축제 담당 공무원.

## 화면 이동

```
              ┌──────────────────────────────────────────┐
              │              W1 진단 입력                 │
              │  (붙여넣기 · PDF · 축제검색 · 직접입력)     │
              └───────┬───────────────────┬──────────────┘
                      │ 읽어오기/선택      │ 직접 입력
                      ▼                   ▼
              ┌──────────────────────────────────────────┐
              │           W2 뽑은 항목 확인               │
              │       (근거를 보며 5축을 사람이 확정)       │
              └───────────────────┬──────────────────────┘
                                  │ 진단하기
                                  ▼
              ┌──────────────────────────────────────────┐
              │        W3 진단 이력 · 경보 결과            │◀─┐
              │  (등급 · 쌍둥이 3곳 · 지도 · 왜 닮았나)     │  │ 저장/삭제 후 복귀
              └───────────────────┬──────────────────────┘  │
                                  │ 이 쏠림에 대비하기       │
                                  ▼                        │
              ┌──────────────────────────────────────────┐  │
              │          W4 행사장 도면 · 쏠림 스캔        │──┘
              │   (배치 편집 + 부하·대기열·통로 침범 판정)   │
              └──────────────────────────────────────────┘
```

## W1 진단 입력

```
┌────────────────────────────────────────────────────────────┐
│ 축제 위험 경보                          진단 | 행사장 도면   │
├────────────────────────────────────────────────────────────┤
│ A-01 · 지자체 축제 담당자용 · 619개 축제 실측                │
│                                                            │
│ 이 축제,                                                    │
│ 작년 그 축제처럼                                            │
│ 무너집니다                                                  │
│                                                            │
│ 기획안을 넣으면 닮은 과거 축제들이 실제로 어떻게 됐는지를…    │
│ ├──────────────── SECTION A — 기획안 입력 ───────────────┤ │
│                                                            │
│ 기획서 붙여넣기                                             │
│ ┌────────────────────────────────────────────────────────┐ │
│ │ (기획안 텍스트 · placeholder 로 예시 기획서)             │ │
│ │                                                        │ │
│ └────────────────────────────────────────────────────────┘ │
│ 또는 PDF 기획서 올리기  [파일 선택]                          │
│ 최대 8,000자 · 하루 45건까지 · 모델명                        │
│ [기획서 읽어오기]   직접 입력하기                            │
│                                                            │
│ 또는 등록된 축제에서 찾기                                    │
│ [        축제 이름        ] [축제 검색]                      │
│ ├──────────────── SECTION C — 진단 이력 ────────────────┤ │
│ (W3 이 같은 페이지 아래에 이어진다)                          │
├────────────────────────────────────────────────────────────┤
│ PROJECT | DATASET | SOURCE | STORAGE   ← 표제란              │
└────────────────────────────────────────────────────────────┘
```

| 상태 | 화면 |
|---|---|
| 정상 | 위 배치. 입력 수단 4가지가 한 화면에 있다 |
| 로딩 | 버튼이 눌린 뒤 전송 중 — 폼 제출이라 브라우저 기본 진행 표시 |
| 빈 상태 | 이 화면 자체가 빈 상태다(입력 전). placeholder 가 예시 기획서를 보여준다 |
| 에러 | 상단에 배너 한 줄 — "기획서 내용을 붙여넣어 주세요", "PDF 에서 글자를 거의 찾지 못했습니다", "오늘 한도(45건)를 다 썼습니다" + 직접 입력 안내 |

## W2 뽑은 항목 확인

```
┌────────────────────────────────────────────────────────────┐
│ ├────────────── SECTION B — 항목 확인 ──────────────────┤ │
│ 뽑은 항목 확인                                              │
│ (출처 배지: TourAPI 등록 정보 / 고정 샘플 경고)              │
│ (못 찾은 항목 안내: 문서에서 찾지 못한 항목이 있습니다 …)     │
│                                                            │
│ 시도       [ 경북            ]                              │
│   “경상북도 김천시 일원에서 개최한다”      ← 원문 근거        │
│ 시군구     [ 김천시          ]                              │
│   “…”                                                      │
│ 개최 월    [ 10월        ▾  ]                               │
│ 테마       [ 음식·미식    ▾  ]                               │
│ 접근성     [ 나쁨         ▾  ]                               │
│ 지역 인구  [ 14          ] 만 명                            │
│   619건 데이터의 같은 시군구 기록에서 가져왔습니다            │
│                                                            │
│ [이 기획안 진단하기]   다른 기획서 넣기                      │
└────────────────────────────────────────────────────────────┘
```

| 상태 | 화면 |
|---|---|
| 정상 | 값마다 그 값이 어디서 왔는지(원문 문장·데이터·샘플)가 아래 붙는다 |
| 로딩 | 없음 — 초안은 이미 서버에 저장돼 있고 이 화면은 편집만 한다 |
| 빈 상태 | 직접 입력 경로: 전 칸 빈 폼 + "문서에서 못 찾은 항목" 안내 |
| 에러 | "입력을 확인해 주세요 — 개최 월은 1~12 사이여야 합니다 · 접근성은 1~5 …" 항목별 나열 |

## W3 진단 이력 · 경보 결과

```
┌────────────────────────────────────────────────────────────┐
│ 진단 이력 (4건)                                             │
│ ┌────────────────────────────────────────────────────────┐ │
│ │ 경북 고령군 · 3월 · 지역 종합 · 인구 3만 · 접근성 나쁨…  │ │
│ │ 이 쏠림에 대비하기 — 행사장 도면 →                       │ │
│ │ 이 진단 지우기                                          │ │
│ │ ▌⚠ 경보: 심각                        ← 등급이 결론 먼저  │ │
│ │ 닮은 축제 3곳이 평소의 2.3~3.3배가 왔습니다               │ │
│ │                                                        │ │
│ │   ┌──────────┐   회색 점 = 619곳 전부                   │ │
│ │   │ · ·  ✕   │   ✕ = 이 기획안의 지역                   │ │
│ │   │ ❶ ❷  ❸  │   ❶❷❸ = 닮은 축제                       │ │
│ │   └──────────┘                                         │ │
│ │ ❶ 고령 대가야축제 (경북 고령군) · 2026년 · 2.27배        │ │
│ │ ❷ 불로초 원정대 (경남 산청군) · 2026년 · 3.28배          │ │
│ │ ❸ 임실N펫스타 (전북 임실군) · 2026년 · 2.58배            │ │
│ │ ▸ 왜 닮았나            ← 접어 둔다. 결론은 위에 펼쳐 둠   │ │
│ └────────────────────────────────────────────────────────┘ │
│ (…최근 50건까지)                                            │
└────────────────────────────────────────────────────────────┘
```

| 상태 | 화면 |
|---|---|
| 정상 | 등급 → 한 문장 → 지도 → 근거 목록 순. 등급 4종: 심각 / 주의 / 위험 근거 못 찾음 / 비교 대상 없음 |
| 로딩 | 없음 — 서버 렌더로 한 번에 온다 |
| 빈 상태 | "아직 진단한 기획안이 없습니다. 위에 기획서를 붙여넣으면 …" |
| 에러 | "진단 이력을 불러오지 못했습니다. 저장은 그대로 남아 있습니다 · 다시 불러오기" |

## W4 행사장 도면 · 쏠림 스캔

```
┌────────────────────────────────────────────────────────────┐
│ B-01 · 경보를 받은 뒤 · 쏠림에 대비하는 배치                 │
│ 행사장 도면                                                 │
│ ┌───────────────────────────────┐ ┌──────────────────────┐ │
│ │                               │ │ 놓기                 │ │
│ │   (부지 지도 위 배치 캔버스)    │ │ [부스][무대][주차장]  │ │
│ │                               │ │ [화장실][출입구]      │ │
│ │   ▨ 무대   ▦ 주차장           │ │ [통로 그리기]         │ │
│ │   ❶ 부스(대기열)               │ │                      │ │
│ │   ═══ 통로(침범 시 강조) ═══   │ │ 배경 지도            │ │
│ │                               │ │ [이동][확대][축소]    │ │
│ │                               │ │ [도면][위성]          │ │
│ │                               │ │                      │ │
│ │                               │ │ 선택한 것            │ │
│ │                               │ │ 이름/인력/선호도      │ │
│ │                               │ │                      │ │
│ │                               │ │ 쏠림 스캔            │ │
│ │                               │ │ 근거: 실측 1.63배     │ │
│ │                               │ │ ❶ 부스1 — 부하 1.6×  │ │
│ │                               │ │ ⚠ 대기열이 통로를 …   │ │
│ │                               │ │ [도면 저장]           │ │
│ └───────────────────────────────┘ └──────────────────────┘ │
│ 기호 — 해칭: 무대 · 점: 주차장 · 점선 띠: 통로 …             │
├────────────────────────────────────────────────────────────┤
│ SHEET | SCALE | ENTRY | ITEMS          ← 표제란              │
└────────────────────────────────────────────────────────────┘
```

| 상태 | 화면 |
|---|---|
| 정상 | 배치하면 스캔이 즉시 따라온다 — 위험 상위 ❶❷❸ · 대기열 · 침범 통로 |
| 로딩 | "도면 편집기를 불러오는 중…" (캔버스는 클라이언트 전용) · 타일은 늦게 와도 배치는 먼저 조작 가능 |
| 빈 상태 | 빈 캔버스 + "도형을 누르면 이름·인력·선호도를 고칠 수 있습니다" · 스캔 자리엔 "부스를 놓으면 부하를 잽니다" |
| 에러 | "도면을 확인해 주세요 — 부스 …의 선호도는 1~5 사이여야 합니다" / "저장에 실패했습니다. 잠시 후 다시" / 스캔 불가 사유("축척이 없어 거리 판정을 못 합니다") |
