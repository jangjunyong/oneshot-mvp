# 기능 1: 사용자가 축제 조건을 넣으면 닮은 과거 축제 3개를 볼 수 있다

## 완료 조건

- [ ] 저장을 누르면 그 줄 아래에 과거 축제 이름 세 개가 보인다
- [ ] 축제마다 개최 연도와 평소 대비 배수(`N.NN배`)가 같이 보인다
- [ ] 축제마다 무엇이 닮았는지 항목 이름이 보인다 (지역·시기·테마·인구·접근성 중)
- [ ] 강원 양구군 · 7월 · 테마 7 · 인구 0.5만 · 접근성 1 → **"비교할 만한 과거 축제가 없습니다"** + 찾아본 범위
- [ ] 같은 값을 두 번 저장하면 두 줄의 축제 이름과 순서가 같다

## 안 되는 경우

- **시군구가 데이터에 없다** → 지역 축을 빼고 네 축으로만 잰다. 좌표를 지어내지 않는다
- **인구·접근성·월이 숫자가 아니거나 범위 밖** → 무엇이 잘못됐는지 짚어 되묻는다. **"비교 대상 없음"으로 답하지 않는다** — 입력 오류와 전례 없음은 다르다
- **임계값 안에 닮은 축제가 없다** → 가장 가까운 걸 억지로 내놓지 않는다

## 이번에 안 하는 것
기획안 텍스트 LLM 파싱 · 디자인·레이아웃 정리

## 건드릴 파일
새로 `lib/festivals.ts` · `lib/match.ts` · `lib/match.test.ts` / 고칠 것 `app/page.tsx`

## 확인 방법
`npm test` → `npm run typecheck` → 배포 URL 에서 김천 조건과 양구 조건을 눌러본다
