## 4. 점수를 벌고 있는 것 — 건드리지 말 것

1. **3단 판정 + 판정 문장 + 출처 셀**. "담당자 숫자를 같은 자의 실측으로 판정한다"는 독창성 자체. 문구만 다듬고 산식·구조 유지.
2. **`/evidence` 곡선 3장 + 일별 표**. 데이터 활용 20점의 실탄.
3. **`/report/check` A4 두 장**. 결재 동선에 맞는 산출물이자 `#보완 피드백 제공`의 실체. 흔적 글자만 뺀다.
4. **PDF 하나 → 5.6초 → 판정**. 첫 화면에 무엇을 더 얹지 말 것.
5. **전국 시군구 × 7년 실측 적재 + 손익분기 회전율(화천 2.93회)**. 화천을 심사위원이 볼 수 있게만 하면 된다.
