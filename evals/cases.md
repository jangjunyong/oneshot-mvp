# evals — 믿을 근거 열 줄

> 강의 p29~30: LLM 앱은 단위 테스트로 안 잡힌다. 필요한 건 프레임워크가 아니라 **표 한 장**이다.
> 이 표가 그대로 작업 지시의 **"완료 조건"** 이 되고, 그게 **에이전트의 눈**이 된다.

실패해야 정상인 케이스가 **5개(06~10)**. 강의 요구는 3개 이상이다.

## 본 표

| # | 입력 | 기대 | 판정 |
|---|---|---|---|
| 01 ★ | 다우데이타 · 다우기술 · 키움증권 | 세 종목이 **한 덩어리**로 이어진다 | 연결요소 == 1 |
| 02 | 현대차 · 기아 | 현대모비스를 거쳐 이어진다 | 경유 회사에 현대모비스가 있는가 |
| 03 | 다우데이타 · 키움증권 · 강원랜드 | **덩어리 2개** + 결론 문장이 그래프 **위에** 먼저 뜬다 | 연결요소 == 2 · 문장이 그래프보다 앞 DOM 순서인가 |
| 04 | 01의 결과에서 관계 클릭 | 보고서명 · 연도 · 항목이 뜬다 | 세 값이 모두 비어 있지 않은가 |
| 05 | 사전 그래프에 경로가 없는 2종목 | 에이전트가 추가 공시를 조회하고 로그를 남긴다 | 작업 로그 1줄 이상 · 조회한 API가 기록되는가 |
| 06 ★ | 무관한 2종목 (후보: 강원랜드 · 오뚜기) | **"관계 없음"** + 확인한 범위 | 관계를 **지어내지 않았는가.** 근거 없는 관계 == 0 |
| 07 ★ | 코스피200 밖 종목 | 온디맨드 시도 후, 없으면 안내 문구 | **500이 아닌가.** 화면에 안내가 뜨는가 |
| 08 ★ | 없는 종목명 ("삼성전자우우우") | 되물음 | 에러 없이 처리되는가 |
| 09 ★ | 1종목만 입력 | "관계는 2종목부터" 안내 | 빈 그래프로 끝나지 않는가 |
| 10 ★ | DART 응답 실패 (키 제거로 재현) | 사전 그래프 결과만으로 축소 응답 + 배지 | 전체가 멈추지 않는가 · 재시도 1회 후 중단하는가 |

## 함정 방어 — 반드시 넣을 것

이 넷이 빠지면 제품이 조용히 무의미해진다.

| # | 입력 | 기대 | 판정 |
|---|---|---|---|
| **11 ★★** | 삼성전자 · 강원랜드 (**둘 다 국민연금이 5% 이상 보유**) | **이어지면 안 된다** | 🔵 간선에서 **기관투자자가 제외**되는가 |
| 12 | 반도체 2종목 (SK하이닉스 · DB하이텍) | 같은 업종 표시는 뜨되 **덩어리 판정에는 안 들어감** | 🔴 제외하고 연결요소를 셌는가 |
| 13 | 배경 회색 노드 클릭·호버·확대 | 아무 일도 안 일어난다 | 이벤트가 발생하지 않는가 (중장년층 오조작 방지) |
| 14 | 같은 입력을 두 번 | **같은 그래프** | 결과가 흔들리지 않는가 (LLM 답변과 다른 지점) |

**11번이 제일 중요하다.** 국민연금·자산운용사는 대형주 대부분의 5% 이상 주주다. 이걸 관계로 쓰면 **국민연금을 거쳐 코스피 전체가 한 덩어리**가 되어 진단이 통째로 무의미해진다. 🔵 대량보유 간선은 **사업회사끼리만** 잇고 기관투자자는 노드에서 뺀다.

## 별도로 재는 것

| 항목 | 기준 |
|---|---|
| 주주 문자열 → `corp_code` 매칭 | 정답 라벨 20~30건 대비 정밀도. Day 3에 라벨 작성 |
| **에이전트/워크플로우 판정** | 무관한 2종목 전부 펼칠 때 API 호출 수. **20회 안쪽이면 워크플로우로 전환** (`docs/FLOW.md` §1) |
| 최대 스텝 | 6스텝 초과 호출이 발생하지 않는가 |
| 응답 지연 | 사전 그래프 히트 1초 이내 · 에이전트 작동 시 첫 로그까지 3초 이내 |

## 정답 라벨 — 전부 미검증

01·02·06의 기대값은 **실제 데이터로 확인한 값이 아니다.** 후보 출처는 [`docs/대체재_검증.md`](../docs/대체재_검증.md)의 Gemini 답변이고, **그 답변에는 명백한 오류가 섞여 있었다.**

| 후보 쌍 | 상태 |
|---|---|
| 다우데이타 · 다우기술 · 키움증권 | 🔲 Day 3 확인 |
| 현대차 · 기아 · 현대모비스 | 🔲 Day 3 확인 |
| 영원무역 · 영원무역홀딩스 | 🔲 Day 3 확인 |
| 동원산업 · 동원시스템즈 | 🔲 Day 3 확인 |
| 강원랜드 · 오뚜기 (무관 후보) | 🔲 Day 3 확인 — **3홉 안에 정말 안 이어지는지.** 이어지면 다른 쌍으로 교체 |

> **추측으로 적은 기대값은 eval이 아니라 또 하나의 암묵지다.**
> DART 정형 API로 실제 관계가 잡히는지 확인한 뒤에만 정답 라벨로 승격한다.

## 쓰는 법

1. 필요한 줄을 골라 작업 지시의 `## 완료 조건`에 그대로 붙인다
2. 에이전트가 읽고 스스로 돌려본 뒤 스스로 고친다
3. 통과하면 커밋. 커밋 하나 = 지시 하나 = 되돌리기 지점 하나

지금은 손으로 돌린다. 자동화는 케이스가 20개를 넘을 때 생각한다 — *"평가 프레임워크를 고르다 이틀을 쓰는 팀이 매번 나옵니다."*
