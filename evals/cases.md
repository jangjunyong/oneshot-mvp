# evals — 표 한 장

> 강의 p29~30: LLM 앱은 단위 테스트로 안 잡힌다. 필요한 건 프레임워크가 아니라 **표 한 장**이다.
> 이 표가 그대로 작업 지시의 **완료 조건**이 된다.

| # | 입력 | 기대 | 판정 |
|---|---|---|---|
| 01 ★ | 김천 조건 (경북 김천시·10월·음식·인구 14만·접근성 2) | 닮은 축제 3개가 나온다 | 개수 == 3 · 거리 임계값 이내 |
| 02 | 01의 결과 | 무엇이 닮았는지 **항목별로** 보인다 | 지역·시기·테마·인구·접근성 중 닮은 축이 표시되는가 |
| 03 ★ | 01의 결과 | 등급과 **한 문장**이 맨 위에 뜬다 | 문장이 표보다 앞 DOM 순서인가 |
| 04 | 03의 등급 | 근거 축제의 **배수와 개최 연도**가 있다 | 두 값이 비어 있지 않은가 |
| 05 | "왜 닮았나" | 기본은 **접혀** 있고 눌러야 펼쳐진다 | 초기 렌더에서 숨겨져 있는가 |
| 06 | 근거 항목 | 출처와 연도가 보인다 | 출처 없는 숫자가 화면에 없는가 |
| **07 ★★** | 닮은 3곳의 중앙 배수 < 1.50 | **"안전합니다"라고 하지 않는다.** "위험 근거 못 찾음" | 안전 판정 문구 0건인가 |
| **08 ★★** | 서울 강남구·2월·음악·인구 119만·접근성 5 | **"비교할 만한 과거 축제가 없습니다"** + 찾아본 범위 | 억지로 가장 가까운 걸 내놓지 않는가 |
| ~~09~~ | ~~닮았는데 결과 기록이 없는 축제~~ | — | 🚫 재현 불가 — 619건 전부 배수가 있다 |
| 10 ★ | 필수 항목이 빠진 입력 | 무엇이 없는지 짚어 되묻는다 | 에러 없이 처리되는가 |
| 11 ★ | 외부 호출 실패 (키 제거로 재현) | 정적 데이터만으로 축소 응답 + 배지 | 전체가 멈추지 않는가 |
| **12 ★★** | 아무 입력 | **방문객 수 예측값을 출력하지 않는다** | 화면의 숫자가 배수(N.NN배)와 연도 네 자리뿐인가 |
| 13 | 서로 다른 입력 10개 | 늘 같은 축제만 나오지 않는다 | 같은 축제가 5회 이상 반복되면 실패 |
| 14 | 같은 입력을 두 번 | **같은 결과** | 결과 축제 id 목록이 일치하는가 |
| 15 | 등급을 흑백으로 | 색 없이도 등급이 구분된다 | 텍스트만으로 읽히는가 |

실패해야 정상인 케이스가 **07·08·10·11·12** 다섯 개. 강의 요구는 3개 이상이다.
**12번이 제일 중요하다.** "몇 명 올 것 같다"를 출력하는 순간 이 제품은 틀릴 수 있는 예측기가 된다.

## 쓰는 법

1. 필요한 줄을 골라 작업 지시의 `## 완료 조건` 에 그대로 붙인다
2. 에이전트가 읽고 스스로 돌려본 뒤 스스로 고친다
3. 통과하면 커밋. 커밋 하나 = 지시 하나 = 되돌리기 지점 하나

지금은 손으로 돌린다. 자동화는 케이스가 20개를 넘을 때 생각한다.
**01·08의 정답 라벨은 기능 1을 만든 뒤 실제로 나온 축제로 채운다.** 추측으로 적은 기대값은 eval 이 아니다.
