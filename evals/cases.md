# evals — 믿을 근거 열 줄

> 강의 p29~30: LLM 앱은 단위 테스트로 안 잡힌다. 필요한 건 프레임워크가 아니라 **표 한 장**이다.
> 이 표가 그대로 작업 지시의 **"완료 조건"** 섹션이 되고, 그게 **에이전트의 눈**이 된다.

**실패해야 정상인 케이스가 5개(06~10) 있다.** 강의 요구는 3개 이상이다.

| # | 입력 | 기대 | 판정 |
|---|---|---|---|
| 01 | 현대차 · 기아 | 현대모비스를 경유해 이어진다 | 경유 노드에 현대모비스가 있는가 |
| 02 | SK하이닉스 · SK텔레콤 | ㈜SK를 경유해 이어진다 | 경로가 반환되는가 (빈 배열 아님) |
| 03 | 현대차 · 기아 · SK하이닉스 | 클러스터 **2개** | 연결요소 개수 == 2 |
| 04 | 01의 결과에서 간선 클릭 | 보고서명 · 연도 · 필드가 뜬다 | 세 값이 모두 비어 있지 않은가 |
| 05 | 사전 그래프에 경로가 없는 2종목 | 에이전트가 추가 공시를 조회하고 로그를 남긴다 | 작업 로그가 1줄 이상인가 · 조회한 API가 기록되는가 |
| 06 ★ | 무관한 2종목 (예: 강원랜드 · 오뚜기) | **"관계 없음"** + 확인한 범위 | 간선을 **지어내지 않았는가**. 근거 없는 간선 == 0 |
| 07 ★ | 코스피200 밖 종목 | 온디맨드 시도 후, 없으면 안내 문구 | **500이 아닌가**. 화면에 안내가 뜨는가 |
| 08 ★ | 없는 종목명 ("삼성전자우우우") | 되물음 | 에러 없이 처리되는가 |
| 09 ★ | 1종목만 입력 | "관계는 2종목부터" 안내 | 빈 그래프로 끝나지 않는가 |
| 10 ★ | DART API 응답 실패 (키 제거로 재현) | 사전 그래프 결과만으로 축소 응답 + 배지 | 전체가 멈추지 않는가 · 재시도 1회 후 중단하는가 |

## 별도로 재는 것

| 항목 | 기준 |
|---|---|
| 주주 문자열 → `corp_code` 매칭 | 정답 라벨 20~30건 대비 정밀도. Day 3에 라벨 작성 |
| 최대 스텝 | 6스텝 초과 호출이 발생하지 않는가 |
| 응답 지연 | 사전 그래프 히트 시 1초 이내 · 에이전트 작동 시 첫 로그까지 3초 이내 |

## 아직 확정 못 한 것

01 · 02 · 06의 **정답은 실제 데이터로 확인한 값이 아니다.** 알려진 지배구조라 잡힐 것으로 보고 적었을 뿐이다.
**Day 3에 실제 DART 응답을 열어 정답 라벨을 확정한다.** 06의 "무관한 2종목"도 3홉 안에 정말 안 이어지는지 그때 확인해서, 이어지면 다른 쌍으로 교체한다.

> 추측으로 적은 기대값은 eval이 아니라 또 하나의 암묵지다.

## 쓰는 법

1. 이 표에서 필요한 줄을 골라 작업 지시의 `## 완료 조건`에 그대로 붙인다
2. 에이전트가 읽고 스스로 돌려본 뒤 스스로 고친다
3. 통과하면 커밋. 커밋 하나 = 지시 하나 = 되돌리기 지점 하나

지금은 손으로 돌린다. 자동화는 케이스가 20개를 넘을 때 생각한다 — *"평가 프레임워크를 고르다 이틀을 쓰는 팀이 매번 나옵니다."*
